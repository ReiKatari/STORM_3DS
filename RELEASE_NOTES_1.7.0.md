# STORM 3DS 1.7.0 (`versionCode = 10700`)

Обновление **1.7.0** переводит окно системной настройки 3DS на единую дизайн-систему **STORM 3DS** и внедряет максимально прокачанный **STORM-компилятор** для Android (`arm64-v8a` / `x86_64`) и Windows x64.

## Что нового в 1.7.0

- **Единое оформление окна «Система 3DS -> Ключи 3DS, спидхаки, SPIR-V и 3D» (`System3dsSetupDialog`)**:
  - Заменены стандартные Material-переключатели, разделители и кнопки на фирменные компоненты STORM 3DS: `WatermelonSwitch`, сгруппированные карточки `SetupSectionCard` (`surface2` с рамкой `colors.line` и радиусом `15dp`), заголовки разделов с акцентным индикатором и моноширинным регистром `WatermelonMono`.
  - Статус-бейджи ключей (`boot9.bin`, `aes_keys`, `seeddb`) теперь адаптируются под все светлые и темные темы STORM (`STORM NIGHT`, `STORM DAY`, `STORM MIDNIGHT` и др.), а блок 3D получил ползунок в цветах темы, кнопки переключения режима, описания каждого пункта и закрепленную нижнюю кнопку сохранения.

- **STORM-компилятор (Максимальный профиль ARM11 JIT + Shader JIT на ARM64 и x64)**:
  - **ARM64 аппаратная таблица `FastDispatch`**: в кодогенератор Dynarmic ARM64 внедрена 8192-элементная прямая хэш-таблица быстрого перехода между базовыми блоками с автоинвалидацией при очистке кэша и самомодифицирующемся коде.
  - **ARM64 прямой `PageTable` без масок (`absolute_offset_page_table` + `UXTW`)**: 32-битные адреса ARM11 транслируются через предвычисленный указатель без лишней инструкции `AND` на каждом обращении к памяти.
  - **Многопроходная IR-оптимизация и Release-сборка без лишних аллокаций**: `A32ConstantMemoryReads` + повторные проходы `ConstantPropagation` / `A32GetSetElimination` / `DeadCodeElimination`, а `VerificationPass` отключен в Release (`#ifndef NDEBUG`).
  - **O(1) чтение кода и генерационно-когерентный кэш `IsReadOnlyMemory`**: чтение инструкций напрямую из `PageTable` и 4-слотовый кэш VMA-диапазонов с проверкой поколения `VMManager::GetGeneration()`, а также увеличенный кэш кода (128 МБ на ARM64, 192-256 МБ на x64) и 1-элементный MRU-кэш вершинных шейдеров PICA200 (`JitEngine`).
  - Профиль **`STORM-компилятор (Максимальный - рекомендуется)`** (режим `3`) добавлен по умолчанию на Android и в настройки Qt Desktop на Windows (`ConfigureDebug` + `[Core]/storm_jit_mode`).

- **Подписанные сборки релиза `1.7.0`**:
  - **`STORM_3DS_1.7.0.apk`**: универсальный подписанный APK для Android (`arm64-v8a` + `x86_64`, `versionCode = 10700`).
  - **`STORM_3DS_1.7.0_Windows_x64.zip`**: подписанный портативный пакет для Windows 10/11 (x64) с Qt 6 и MSVC CRT.
