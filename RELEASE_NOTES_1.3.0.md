# STORM 3DS 1.3.0 (`versionCode = 10300`)

Обновление 1.3.0 полностью очищает настройки от устаревших параметров DS/DSi/GBA/WFC, исправляет запуск системного HOME Menu Nintendo 3DS, ускоряет ARM11 JIT-компилятор (Dynarmic) и аудиоподсистему для слабых и старых устройств, включает запись логов приложения по умолчанию и переносит стиль `Цвет экранных кнопок` на экран назначения физических клавиш.

## Что нового и исправлено в 1.3.0

- **Запуск HOME Menu Nintendo 3DS (`RomListActivity` + `EmulatorLaunchValidatorDelegate`)**:
  - Устаревший пункт запуска DS/DSi-прошивки объединен в единый пункт "Запустить HOME Menu 3DS".
  - При отсутствии системных архивов HOME Menu в `STORM 3DS/nand` вместо ошибочного окна "укажите дамп DS BIOS" отображается понятный 3DS-диалог с переходом к настройкам ключей 3DS или установке системных `.cia`.
- **Чистая конфигурация Nintendo 3DS и удаление не-3DS элементов**:
  - Удален экран-пережиток `Файлы BIOS и прошивки` (`CustomFirmwarePreferencesFragment` / `pref_custom_firmware.xml`) с загрузчиками BIOS DS/DSi и дублирующим списком `Тип консоли` (`Console Type`).
  - Из разделов `Система`, `Видео`, `Аудио`, `Сохранения` и настроек игры убраны неиспользуемые пункты от DS/DSi (`arm9_overclock`, `WFC`, Slot-2/GBA, DS LCD/Hinge и др.).
  - Экран `Профиль системы Nintendo 3DS` подключен к реальному `SystemSaveGame` (`Service::CFG` в NAND 3DS): имя пользователя 3DS, день рождения, баланс Play Coins (`0-300`), MAC-адрес и Console ID.
  - Добавлены живая проверка системных файлов 3DS (`boot9.bin`, `aes_keys.txt`, `seeddb.bin`, `nand`, `sdmc`), переключатель сети `Pretendo / Nimbus`, режим `SDMC` сохранений и поддержка 3DS-камеры.
- **Ускорение ARM11 JIT (Dynarmic), аудио HLE и режим для слабых и старых устройств**:
  - В `arm_dynarmic.cpp` настроены целевой профиль ARM11 `ArchVersion::v6K`, `always_little_endian = true`, отключение лишних хуков (`hook_isb`, `hook_hint_instructions`, `check_halt_on_memory_access`), безопасное сворачивание констант `IsReadOnlyMemory(VAddr)`, RAM-адаптивный кэш кода (`32-128 МБ`) и 3 профиля JIT (`Точный`, `Быстрый`, `Турбо`).
  - Исправлено скрытое снижение FPS в `MelonEmulator`: по умолчанию теперь используется быстрый `HLE`-режим DSP вместо тяжелого `LLE`.
  - В `Настройки -> Система` добавлен пресет в 1 нажатие "Оптимизация для слабых и старых устройств" (`Турбо ARM11 JIT`, 75% ЦП, `1x`, отключение правого глаза, пропуск дублей кадров, асинхронные шейдеры, FMV-хак, SPIR-V, HLE-звук).
- **Запись логов приложения включена по умолчанию**:
  - Параметр `system_app_log_file_enabled` теперь активен по умолчанию (`true`) и автоматически сохраняет журнал в `STORM 3DS/logs/STORM_3DS.log`.
- **Переработанное оформление `Назначение физических клавиш` (`InputSetupScreen`)**:
  - Экран переработан в визуальном стиле `Цвет экранных кнопок` с синхронизацией активной цветовой темы: верхняя визуальная панель Nintendo 3DS (`ZL`/`L`/`R`/`ZR`, Circle Pad, крестовина, глянцевые `X/Y/A/B`, C-Stick, `SELECT/HOME/START`), счетчик привязок, глянцевые 3D-колпачки и объемные 3D-бейджи назначенных физических клавиш.
- **Полная локализация 10 языков и единая сборка**:
  - Все новые настройки, пресеты и элементы интерфейса переведены для всех 10 локалей (`en`, `ru`, `es`, `fr`, `de`, `it`, `pt-BR`, `id`, `zh-Hans`, `ja`).
  - Публикуется единый универсальный подписанный файл `STORM_3DS_1.3.0.apk` (`arm64-v8a` + `x86_64`, `STORM_ENABLE_ADRENOTOOLS=ON`).
