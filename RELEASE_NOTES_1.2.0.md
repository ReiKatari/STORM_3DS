# STORM 3DS 1.2.0 (`versionCode = 10200`)

Обновление 1.2.0 фокусируется на полной локализации интерфейса на всех 10 поддерживаемых языках, исправлении открытия диалога настроек 3DS и корректном выборе языка системы Nintendo 3DS по умолчанию.

## Что нового и исправлено в 1.2.0

- **Рабочий пункт "Ключи 3DS, спидхаки, SPIR-V и 3D" (`SystemPreferencesFragment` + `System3dsSetupDialog`)**:
  - Подключен обработчик нажатия для `system_3ds_setup`, чтобы пункт в разделе `Настройки -> Система` стабильно открывал окно настройки ключей дешифрования (`boot9.bin` / `seeddb.bin` / `aes_keys.txt`), параметров шейдеров SPIR-V, спидхаков и 3D.
  - Добавлена безопасная распаковка `ContextWrapper` (`Context.findComponentActivity()`) в `System3dsSetupDialog` во избежание сбоев отображения диалога.
- **100% локализация интерфейса для всех 10 языков (`en`, `ru`, `es`, `fr`, `de`, `it`, `pt-BR`, `id`, `zh-Hans`, `ja`)**:
  - Локализованы названия и значения опций во всех выпадающих списках и настройках: режим производительности (`Энергосбережение`, `Баланс`, `Макс. производительность`, `Игровой режим`), модель (`Базовая 3DS`, `New 3DS`), разгон ЦП (`Без разгона` и др.), термины `ЦП` / `ГП` / `ОЗУ`, режимы 3D, фильтры текстур, скины консоли и позиции HUD.
  - Переведены XML-диалоги (`dialog_dual_screen_presets.xml`, `dialog_styled_update.xml`), системные отчеты утилит 3DS, NetPlay-лобби, экранный переводчик, меню паузы, профиль игрока, индикаторы слайдера 3D-глубины, редактор комбо-кнопок и сервисное уведомление `Storm3dsForegroundService`.
  - Убраны устаревшие термины и упоминания DS в строковых ресурсах, обеспечен 100% паритет ключей и плейсхолдеров во всех 10 локалях.
- **Язык системы Nintendo 3DS по умолчанию как на устройстве**:
  - Значение `3ds_system_language` по умолчанию изменено на `"-1"` ("Как в системе" / "System Default").
  - Добавлено автоматическое сопоставление активной локали приложения/ОС с системным языком эмулятора (`MelonEmulator.resolveDevice3dsSystemLanguage`).
- **Исправление холодного запуска одиночного ROM через `ACTION_VIEW` (`RomListActivity`)**:
  - Исключено обращение к `ViewModelLazy` из потока `Dispatchers.IO` при открытии `.3dsx`/ROM-файла напрямую из внешнего намерения.
- **Стандартизация сборки**:
  - Начиная с версии 1.2.0 публикуется единая универсальная подписанная сборка `STORM_3DS_1.2.0.apk` (`arm64-v8a` + `x86_64`, `STORM_ENABLE_ADRENOTOOLS=ON`).
