# STORM 3DS 1.5.0 (`versionCode = 10500`)

Обновление 1.5.0 полностью устраняет проблемы с внутриприложенческим обновлением, перерабатывает фирменный режим 3D-глубины без разделения на два экрана и без двойного размытия, добавляет глубокую оптимизацию компилятора, Vulkan/OpenGL и планирования потоков ЦП, а также исправляет ряд функциональных и интерфейсных ошибок.

## Что нового и исправлено в 1.5.0

- **Чёткий одноэкранный режим 3D-глубины (`GyroParallax`) без разделения экрана и размытия**:
  - **Новый 2-проходный шейдер параллакса (`vulkan_present_gyro.frag`, `opengl_present_gyro.frag`)**: полностью удалено смешивание левого и правого кадра `mix(left_col, right_col, eye_mix)`, вызывавшее постоянное двоение и мыло; вместо этого вычисляется карта глубины из реальной стерео-диспарности левого/правого глаза и перцептивной перспективы с 5-точечным сглаживанием глубины, а итоговый пиксель берётся из одного чёткого кадра с деликатным объёмным освещением окна глубины.
  - **Мгновенное применение 3D-режимов без перезапуска (`storm3ds_extensions.cpp`, `RendererVulkan`, `RendererOpenGL`)**: переключение режима теперь выставляет `shader_update_requested = true`, обновляет макет и перезагружает пайплайн на лету; нижний сенсорный экран остаётся строго 1:1 без сдвигов.
  - **Единый порядок режимов в меню и полная поддержка Vulkan + OpenGL**: `Гироскопический 3D-параллакс` размещён сразу после `Отключён`, исправлено отображение режимов в настройках игры и быстром меню 3DS, сенсорное масштабирование ограничено сплит-режимами (`1, 2, 6`).

- **Надёжное сквозное обновление внутри приложения (главный экран и Настройки)**:
  - **Прямая установка из Настроек**: экран проверки обновлений (`ManualUpdateChecker`) теперь использует стилизованное окно со списком изменений (`Markwon`) и скачивает/проверяет/устанавливает APK внутри приложения через `GitHubUpdateInstallManager` вместо открытия браузера.
  - **Исправление R8 `fullMode`, зеркала SGW и проверки подписи на Android 9-16**: добавлены правила ProGuard для `GitHubApi`/`github.dtos`, переключён клиент на лёгкий эндпоинт `/api/programs/releases?repo=STORM_3DS`, нормализованы относительные и прокси-URL, исправлена проверка `apkContentsSigners` в `signerDigests`, добавлена проверка внутри цикла зеркал, параллельный опрос GitHub + SGW и полноценный запрос разрешения `REQUEST_INSTALL_PACKAGES` с автозапуском установки при возврате.
  - **Точная обработка сети и каналов**: офлайн-режим больше не сообщает ложное «Установлена актуальная версия», `provideJson()` включает `coerceInputValues = true`, `HttpRedirectHelper` блокирует небезопасные редиректы, а в Настройки добавлен канал предрелизов.

- **Глубокая оптимизация производительности и быстрого запуска**:
  - **Релизные флаги C++/NDK (`app/build.gradle.kts`, `core/src/CMakeLists.txt`)**: включены `-O3`, векторизация (`-fvectorize`, `-fslp-vectorize`), `-funroll-loops`, `-Wl,-O3,--gc-sections,--icf=safe`, `DYNARMIC_IGNORE_ASSERTS=ON`, отключены тяжёлые отладочные проверки в релизных сборках Android.
  - **Привязка к производительным ядрам и приоритеты потоков (`EmulationThreadCpuPolicy`, `native.cpp`, Vulkan worker'ы)**: главный поток эмуляции закрепляется на производительных ядрах (`setActive(true)`, `nice -8`), потоки `VulkanWorker`/`VulkanPresent` получают высокий приоритет (`nice -8`), а фоновые компиляторы шейдеров/пайплайнов работают с `nice +4`, не мешая кадрам.
  - **Оптимизации Vulkan / OpenGL ES**: убраны полные GPU-барьеры `eAllCommands` в `PresentWindow::CopyToSwapchain`, добавлена поддержка `GL_EXT_buffer_storage` для persistent ring buffer в OpenGL ES 3.2, сэмпловый шейдинг `sampleShadingEnable` включается только при MSAA > 1, добавлен повтор ожидания фенсов `eErrorInitializationFailed` для Mali, оптимизированы кольцевые буферы Android Vulkan (`128 MiB` upload / `32 MiB` stream), а `3ds_spirv_opt` и `3ds_audio_stretch` по умолчанию отключены для плавного фреймтайма (`3ds_log_filter` = `*:Warning`).
  - **Холодный старт и память**: фоновая инициализация зеркала настроек и отчёта устройства в `MelonDSApplication`, удаление блокирующей файловой пробы в `CoilModule`, дедупликация JNI-обновлений макета в `Storm3dsSurfaceRenderCoordinator`, кэширование `rom_metadata_mirror.json` и переиспользование буфера пикселей для Rewind.

- **Исправления функционала и интерфейса**:
  - Добавлена поддержка расширения `.z3ds` (`ThreeDS` + `CompressedRomFileProcessor`).
  - Отключение всех читов теперь корректно очищает нативный `CheatEngine` и сохраняет пустой файл читов.
  - Дублирование слотов сохранения теперь копирует нативный `.cst`-файл, использует локализованный шаблон копии и безопасное определение имени ROM.
  - Переключение паузы из уведомления `Storm3dsForegroundService` синхронизируется с `EmulatorViewModel`, исправлено отображение HUD-разрешения 3DS (`400x240`), сохраняется масштаб разрешения из меню паузы, загрузка базы читов импортирует 123 встроенные базы 3DS Gateway вместо несовместимых DS-кодов, а также очищены остаточные строки на всех 10 языках.
