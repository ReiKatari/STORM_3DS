# STORM 3DS 1.6.0 (`versionCode = 10600`)

Обновление **1.6.0** добавляет официальную сборку **STORM 3DS для Windows x64** с проработанным интерфейсом и корректным HiDPI-масштабированием на экранах с любым DPI, а также выравнивает распознавание `.bcxi` и `.z3ds` в настольной библиотеке игр.

## Что нового в 1.6.0

- **Поддержка `.bcxi` и `.z3ds` в настольной библиотеке Qt (`game_list.cpp`, `loader.cpp`, `ncch_container.cpp`, `citra_qt.cpp`)**:
  - В `GameList::supported_file_extensions` добавлены `bcxi` и `z3ds` - теперь бандлы `.bcxi` (`Игра + Update + DLC`) и сжатые образы `.z3ds` отображаются прямо в библиотеке на ПК без ручного открытия через `File -> Load File`.
  - Исправлен фильтр расширений в диалоге распаковки Z3DS (`*.zcia *.zcci *.z3ds *.z3dsx *.zcxi`) и расширен список перетаскивания Drag & Drop.

- **Первая официальная Windows x64 сборка `STORM_3DS_1.6.0_Windows_x64.zip` (портативный пакет с MSVC CRT и Qt6)**:
  - Собран `STORM_3DS.exe` с метаданными версии `1.6.0` (`STORM TEAM`), иконкой `storm3ds.ico`, поддержкой портативного каталога `user/` рядом с `STORM_3DS.exe` и `%APPDATA%\STORM 3DS`, и проверкой подписи `STORM SERTIFICATE`.
  - Добавлены две новые фирменные темы Qt: **STORM Dark (Flagship)** (тема по умолчанию) и **STORM Light**, а также нативная темная рамка заголовка Windows 10/11 (`DwmSetWindowAttribute`).
  - Добавлен переключатель четкого одноэкранного **3D-параллакса глубины (`GyroParallax`)** в настройки графики ПК-версии (без разделения и двоения кадра) с поддержкой параллакса курсором мыши.
  - Настроен встроенный проверяльщик обновлений для Windows (`WinHTTP` + TLS) с проверкой GitHub `ReiKatari/STORM_3DS` и зеркала `stormgamesworld.ru` без ложных срабатываний внутри ветки версий.

- **Честное HiDPI-масштабирование и поддержка мониторов на Windows (`citra_qt.cpp`, `bootmanager.cpp`, `configure_ui`)**:
  - Политика DPI на Windows переведена на честный дробный режим `PassThrough` вместо искусственного округления `Floor`/`Round`, добавлена настройка **Масштаб интерфейса (`UI Scale`: `Авто`, `100%`, `125%`, `150%`, `175%`, `200%`)** и крупные иконки игр `64x64` в настройках интерфейса.
  - Улучшен пересчет физического размера кадра (`OnFramebufferSizeChanged` с точным округлением `std::lround`), добавлена автоматическая реакция на смену монитора/DPI (`DevicePixelRatioChange` + `QWindow::screenChanged`) и субпиксельная точность кликов мыши при масштабе 125%-200%.

- **Android-сборка `STORM_3DS_1.6.0.apk` (`versionCode = 10600`)**:
  - Включает все улучшения версии `1.5.0` (четкий одноэкранный 3D-параллакс на Vulkan и OpenGL ES, сквозное обновление внутри приложения, `-O3`/CPU affinity/Vulkan/GLES оптимизации, фиксы `.zcia`/`.z3ds`/читов/сейвов) и актуальную синхронизацию ядра `1.6.0`.
